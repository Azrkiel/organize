# Organize

A personal, minimalist study app: courses, notes, tasks, calendar, flashcards, focus sessions, and recorded lectures.

Built with Next.js 15, TypeScript, Tailwind, shadcn/ui, and Supabase. Runs entirely on free tiers.

## Development

```bash
cp .env.example .env.local   # then fill in your Supabase URL and anon key
npm install
npm run dev
```

Other commands: `npm run test`, `npm run lint`, `npx tsc --noEmit`, `npm run build`.
